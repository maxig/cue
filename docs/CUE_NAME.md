# Why Cue?

**Cue** works because it has a few useful meanings:

A **cue** is a signal to start speaking or presenting, like “that’s your cue.” For a screen-recording/message app, it implies: record when you’re ready, send the signal, move work forward.

It also suggests a **prompt**: the app helps you explain something clearly without needing a live meeting.

And phonetically, it feels short, clean, and brandable. One syllable, easy to say, good as a button label: **“Send a Cue”**, **“Record a Cue”**, **“Cue me in.”**

The possible downside is ambiguity. “Cue” can also mean a pool stick or a line in a playlist/queue context, so the product positioning would need to make the meaning obvious. For example:

**Cue — async video updates for teams**
**Cue — record your screen, explain faster**
**Cue — video messages that move work forward**
